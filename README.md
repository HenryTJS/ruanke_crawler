# 软科大学排名爬虫与可视化

### 介绍
包括中国大学排名等七个排名的爬虫代码（七合一），以及中国大学数据的可视化数字大屏实现。

### 爬虫使用方法
1. 运行 *crawl.py* 文件，根据注释以及自身需求输入数字以爬取相关大学排名表格；
2. 运行 *payload.py* 文件，将爬取结果整理并输出为 *output.csv*（按 univCode 以文本类型从小到大排序）。

### 可视化使用方法
1. 运行 *convert_to_js.py* 文件，将 *output.csv* 转换为前端可嵌入的 *data.js* 数据文件；
2. 直接打开 *index.html* 即可看到可视化结果（纯前端单页，无需服务器）。
3. 运行 *rank_to_js.py* 文件，将文件名不包含“名单”或“总榜”的排名 CSV 合并为 *ranking_data.js*；包含这两个关键词的文件会自动跳过。

### 可视化功能
2. 运行 *rank_to_js.py* 文件生成排名数据；
3. 直接打开 *index.html* 即可看到可视化结果（纯前端单页，无需服务器）。
- **筛选面板**：支持省份、类别、层次、主管部门、标签等多维度平铺多选筛选，以及关键词搜索；
- **学科/专业筛选**：支持学科两级代码树和专业三级代码树，选择后可筛出开设对应学科或专业的高校；
- **学科/专业等级筛选**：支持按中国最好学科排名等级和中国大学专业排名评级筛选高校，例如选择专业等级“B”即可筛出至少有一个专业评级为 B 的高校；
- **排名数据**：展示中国大学排名、中国高职院校排名、中国大学专业排名和中国最好学科排名；排名覆盖统计会随筛选结果更新；
- **高校列表**：展示筛选后的高校明细，点击可查看详情及排名信息。
